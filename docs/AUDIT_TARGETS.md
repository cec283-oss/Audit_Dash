## 공법 1개를 볼 때 감사 체크 순서 (대시보드 흐름)

1. **리스크 지수·영역별 레이더**로 어느 영역(스펙/변경/인터락/PM·BM/설비 구성/공정능력)이 문제인지 본다
2. **공정흐름도**에서 빨갛게 빛나는 스텝을 찾는다 (치명 포함 스텝)
3. 스텝을 누르면 리스크 포인트·설비 집계·타임라인·이력이 그 스텝으로 좁혀진다
4. **호환설비 / 모델** 전환으로 특정 설비 문제인지, 모델 공통 문제인지 가른다
5. 타임라인에서 BM → (Qual 전 LOT) → 인터락 강제 해제 → 변경 같은 **사건 순서**를 확인한다
6. 상세 이력 표를 CSV로 내려받아 감사 조서 근거로 첨부한다
